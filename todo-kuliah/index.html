    Penjelasan Konsep & Teknologi

    Ringkasan teknologi yang dipakai pada aplikasi ini.

    Git dan GitHub
    • Git: sistem version control untuk mencatat riwayat perubahan kode (commit).
    • Branch: cabang kerja terpisah untuk mengembangkan fitur tanpa mengganggu branch utama.
    • Merge: menggabungkan riwayat commit dari satu branch ke branch lain.
    • Merge Conflict: terjadi saat dua branch mengubah baris yang sama, sehingga harus dipilih dan diselesaikan manual.
    • Pull Request: permintaan di GitHub untuk meninjau dan menggabungkan branch ke main.
    • Push dan Pull: push mengirim commit lokal ke GitHub, pull mengambil perubahan dari GitHub.
    • .gitignore: daftar file yang tidak ikut dilacak, misalnya node_modules dan .env.
    npm (Node Package Manager)
    • Mengelola paket (library) yang dipakai proyek lewat npm install.
    • package.json: menyimpan nama proyek, daftar paket, dan scripts (dev, build, preview).
    • dependencies: paket yang dibutuhkan aplikasi saat berjalan.
    • devDependencies: paket untuk pengembangan saja, seperti Vite dan TypeScript.
    • Semantic versioning: MAJOR.MINOR.PATCH. Tanda ^ boleh update minor/patch, ~ hanya patch.
    TypeScript
    • JavaScript dengan sistem tipe, sehingga kesalahan terdeteksi sebelum aplikasi dijalankan.
    • Dipakai di aplikasi ini: tipe primitif (string, number, boolean), array, interface Tugas, type alias dan union type (Status, Prioritas, Filter), serta generics (simpan<T>, muat<T>).
    Vite, Compiler, Transpiler & Bundler
    • Compiler: menerjemahkan kode sumber ke bentuk lain yang bisa dijalankan atau diperiksa. tsc memeriksa tipe TypeScript.
    • Transpiler: mengubah kode ke bahasa/versi lain yang levelnya setara, misalnya TypeScript ke JavaScript. Pada Vite tugas ini dikerjakan esbuild.
    • Bundler: menggabungkan banyak modul dan aset menjadi sedikit file yang dioptimalkan (minify). Vite memakai Rollup saat npm run build.
    • Vite: saat development menyajikan modul ES langsung sehingga sangat cepat (hot reload), dan saat build menghasilkan folder dist yang siap di-deploy.
    Environment Variables
    • Konfigurasi aplikasi disimpan di file .env dan dibaca lewat import.meta.env.
    • Variabel harus berawalan VITE_ agar terbaca, dan nilainya akan terlihat di browser. Karena itu hanya untuk data non-rahasia seperti nama dan versi aplikasi.
    • .env tidak diunggah ke GitHub (ada di .gitignore), sedangkan .env.example diunggah sebagai contoh.
